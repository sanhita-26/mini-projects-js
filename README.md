# 🚀 JavaScript Mini Projects

A collection of beginner-to-intermediate JavaScript projects built to strengthen core concepts and hands-on skills.

---

## 📂 Projects Included

### 🎯 All-Javascript-Concepts
Covers fundamental JavaScript concepts like variables, loops, functions, DOM manipulation, and event handling.

---


### 🎲 Number Guessing Game
A fun game where the user guesses a randomly generated number.  
Focuses on logic building and conditional statements.

---

### 🔐 Random Password Generator
Generates secure random passwords of 12 characters.
Covers string manipulation and randomness.

---

### 🌡️ Temperature Conversion
Converts temperature between Celsius & Fahrenheit.  
Strengthens understanding of functions and formulas.

---

### 🔢 Counter Program
A simple counter with increment, decrement, and reset functionality.  
Focuses on DOM updates and event handling.

---

### 🎲 Dice Roller
Simulates rolling a dice and generates random outcomes.  
Demonstrates use of Math functions and UI interaction.

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Vanilla JS)

---

## 🎯 Purpose
- Practice core JavaScript concepts
- Build interactive UI components
- Improve problem-solving skills
